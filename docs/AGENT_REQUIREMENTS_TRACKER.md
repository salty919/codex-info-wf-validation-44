## 登録手順

1. 主担当が変更前に行を追加し、要求ID・所有ファイル・受入ゲートを固定する。
2. 実装担当は行の範囲外を変更せず、rawコマンド結果を保存する。
3. 新しい独立サブエージェントが、実装者の結論を受け取らず、同じSHAの成果物を再評価する。
4. 独立評価がPASSになるまで、行とリリースマニフェストをHOLDのままにする。
