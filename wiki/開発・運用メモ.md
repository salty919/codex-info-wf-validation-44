# 開発・運用メモ

## 技術スタック

- 言語: Rust（Cargo）
- GUI: Slint（宣言的UI）
- データ保存: SQLite（履歴）
- 認証・状態取得元: Codex App Server（JSON-RPC）

## 起動時に見える主画面

- 認証パネル（認証・再取得）
- 残量表示（7セルゲージ）
- リセット残時間
- モデル別トークン使用量とUSD見積表示（モデルごと）
- ステータス文言（未認証/警告/エラー）

## 開発時の重要ポイント

- 依存ライブラリを増やす変更をする場合、`Cargo.toml` / `Cargo.lock` を必ず整合させる
- UIの調整は`ui/theme.slint`、`ui/components.slint`のトークンやコンポーネントを優先（コード側で座標を直書きしない）
- 言語切替や文言追加は、ロケール仕様に準拠
- 履歴表示は実データに基づいて更新し、重複表現を避ける

## 更新ルール（Wiki）

- 本Wikiは1ドキュメント単位で要約を増やすより、ページ分割して責務を明確にする
- 仕様変更がある場合は、該当ページの「日付」と「影響範囲」を更新する
- 重要な仕様変更は[README.md](../README.md)にも反映し、運用手順と齟齬がないことを確認

## GitHub Wiki 反映ガイド

本リポジトリのWikiは、GitHub側で別リポジトリとして管理されます（`<owner>/<repo>.wiki`）。

### 実行手順

```bash
cd /tmp
git clone https://github.com/salty919/codex_info_v2.wiki.git codex_info_v2.wiki
cd codex_info_v2.wiki

# 1) このリポジトリ側のwikiファイルをコピー
cp -r /home/salty/code/codex_info_v2/wiki/* .

# 2) 追加・更新
git add .
git commit -m "docs: add wiki pages for Codex Info"
git push
```

既定では`main`リポジトリで編集履歴は`master`相当として扱われる運用に依存するため、事前にCI/権限を確認してください。

### 注意

- ローカルの認証が未設定の場合、`git clone` / `git push`時に失敗します。PAT または SSH が必要です。
- `.md`ファイル名はGitHub Wikiのページタイトルとして解釈されるため、必要なら英語名ファイル（`Home.md`等）も併記すると運用しやすいです。
