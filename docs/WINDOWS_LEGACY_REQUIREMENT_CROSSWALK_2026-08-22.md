# Windows要求・既存台帳 逆引き対応表（2026-08-22）

状態: `EXTRACTION_INCOMPLETE / IMPLEMENTATION_EVIDENCE_NOT_EVALUATED`

## 1. 目的と判定規則

Windows版の226件だけを新しい正本として扱うと、それ以前に記録したnative、REST、daemon、
DB保護、installer、試験ギャップの要求が黙って消えるおそれがある。本表は、既存4台帳の
全96 IDを、現在のWindows原子要求またはWindowsの外側に残るglobal正本へ逆引きする。

- `WIN-*` は `docs/atomic-contracts/` の同一ID具体契約で閉じる。
- `GLOBAL:<source-id>` はWindowsだけへ縮退できない要求であり、元IDをglobal正本として
  保持する。Windows側へ影響する部分がある場合は併記した `WIN-*` も必須とする。
- `alias` は要求数を水増しする別要求ではなく、同じ観測可能契約の旧名である。
- 元台帳にある過去の `verified` / `implemented` は現行成果物のPASS証拠として使わない。
  同一SHAの再評価が終わるまでは、実装状態に関係なく本表全体をHOLDとする。
- source IDが1件でも欠ける、targetが存在しない、またはglobal要求をWindowsだけへ
  誤って縮退した場合は抽出FAILである。
