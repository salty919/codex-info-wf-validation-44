# 導入と起動ガイド

## 目的

Codex Infoを自分のWSL環境で起動し、利用率をX Windowで確認できる状態にする手順です。

## 事前準備

1. Rust/Cargo を導入

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

2. X11 / WSLg が表示可能であること

```bash
echo "$DISPLAY"
```

3. `codex` CLI が利用可能

```bash
codex login status
codex app-server --help
```

## インストールと起動

```bash
git clone https://github.com/salty919/codex_info_v2.git
cd codex_info_v2
./run.sh
```

別ロケーションに履歴を保存したい場合は、起動前に環境変数で上書きします。

```bash
CODEX_INFO_DATA_DIR="$PWD/data" ./run.sh
```

## 初回認証フロー（目安）

1. 「認証を開始」を押す  
2. 「認証ページを開く」を押す  
3. ブラウザでOpenAIアカウントにログインし、Codexアクセスを許可  
4. X Windowへ戻り「認証状態を確認」を押す  

## 起動後のよく見る設定値

- 画面サイズ（Main/Threads/Legal）：固定
- Graph初期サイズ：`940x640`（最小は`700x480`）
- 1分ごとにレート制限を再取得
- レポート用途で状態を切り替える環境変数
  - `CODEX_INFO_PREVIEW=auth|normal|warning|reset-warning|error|zero|full|monthly|unlimited|idle|legal`
  - グラフのみなら `CODEX_INFO_PREVIEW=graph|graph-old`
  - サイズ変更は `CODEX_INFO_PREVIEW_SIZE=700x480` のように指定

## トラブルシュート

- 画面が起動しない
  - `DISPLAY` が未設定でないか確認
  - `codex app-server --help` が成功するか確認
- 認証が進まない
  - `codex login status` でログイン状態を確認
  - ブラウザ側のログイン／許可を再実行
